# 🎬 Movie Recommendation System

A machine learning based movie recommendation system that recommends
movies based on their genres and descriptions.

## 🚀 Features

- Content-based movie recommendations
- TF-IDF text vectorization
- Cosine similarity
- Simple command-line interface
- Displays similarity scores
- Handles invalid movie names

## 🛠️ Technologies

- Python
- Pandas
- Scikit-learn
- TF-IDF
- Cosine Similarity

## 📂 Project Structure

Recommendation-System/
│
├── recommendation.py
├── movies.csv
└── README.md

## ⚙️ Installation

Install the required libraries:

pip install pandas scikit-learn

## ▶️ Run

python recommendation.py

## 🧠 Machine Learning Approach

This project uses content-based filtering.

Movie genres and descriptions are converted into numerical
representations using TF-IDF.

Cosine similarity is then used to calculate how similar
different movies are.

## 📊 Example

Input:
Inception

Output:
1. Interstellar
2. The Matrix
3. Avatar
4. Jurassic Park
5. Avengers Endgame
